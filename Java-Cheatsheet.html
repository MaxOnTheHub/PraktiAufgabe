Java-Cheatsheet - Die ersten Schritte

1. Das kleinste Programm

Die Datei heißt Sandbox.java. Klassenname und Dateiname müssen zusammenpassen.

public class Sandbox {
    public static void main(String[] args) {
        System.out.println("Hallo Welt!");
    }
}

Euren eigenen Code schreibt ihr zunächst zwischen die geschweiften Klammern der main-Methode. Die Anweisungen werden von oben nach unten ausgeführt.

2. Variablen - Werte merken

Eine Variable hat einen Datentyp, einen Namen und einen Wert.

int alter = 14;

Allgemeiner Aufbau: Datentyp name = wert;

DatentypWofür?Beispiel
intGanze Zahlenint punkte = 0;
longBesonders große ganze Zahlenlong aufrufe = 47_548_839_843L;
doubleKommazahlendouble preis = 2.50;
booleanWahr oder falschboolean gefunden = false;
charEin einzelnes Zeichenchar auswahl = 'A';
StringTextString name = "Alex";
  • Kommazahlen werden im Code mit einem Punkt geschrieben: 2.50.
  • Text steht in doppelten Anführungszeichen, ein char in einfachen.
  • String wird großgeschrieben, die anderen Datentypen in der Tabelle klein.
  • Das L kennzeichnet eine long-Zahl. Unterstriche in Zahlen verbessern nur die Lesbarkeit.
  • Ein int reicht von -2.147.483.648 bis 2.147.483.647. Für größere Zahlen braucht ihr zum Beispiel long.

3. Werte ändern

int punkte = 0;
punkte = 5;
punkte = punkte + 1;
punkte++;

Der Datentyp steht nur beim Anlegen der Variablen davor. punkte++ erhöht den Wert um eins. Nach diesen vier Zeilen ist punkte gleich 7.

Ein Wert, der nicht mehr geändert werden darf:

final int MAX_VERSUCHE = 7;

4. Etwas ausgeben

String name = "Alex";
int punkte = 3;

System.out.println("Hallo!");
System.out.println(name);
System.out.println("Punkte: " + punkte);
System.out.print("Dein Tipp: ");

println beginnt nach der Ausgabe eine neue Zeile. print bleibt in derselben Zeile. Mit + könnt ihr Text und Werte verbinden.

6. Werte vergleichen

Ein Vergleich ergibt immer true oder false.

ZeichenBedeutungBeispiel
==Gleichtipp == zugposition
!=Ungleichtipp != zugposition
<Kleinertipp < zugposition
>Größertipp > zugposition
<=Kleiner oder gleichpunkte <= 10
>=Größer oder gleichalter >= 14

Wichtig: = weist einen Wert zu. == vergleicht Werte.

Textinhalte vergleicht ihr mit .equals(), nicht mit ==:

String name = "Alex";
boolean gleicherName = name.equals("Alex");

7. Entscheidungen mit if / else

int tipp = 40;
int zugposition = 65;

if (tipp < zugposition) {
    System.out.println("Die gesuchte Zahl ist hoeher.");
} else if (tipp > zugposition) {
    System.out.println("Die gesuchte Zahl ist niedriger.");
} else {
    System.out.println("Gefunden!");
}

if bedeutet wenn, else if bedeutet sonst wenn, else bedeutet sonst.

Bedingungen verbinden:

boolean imBereich = tipp >= 1 && tipp <= 100;
boolean passendeAuswahl = tipp == 1 || tipp == 2;
boolean nichtGefunden = !gefunden;

&& = und, || = oder, ! = nicht. Die letzte Zeile setzt voraus, dass eine boolean-Variable namens gefunden existiert.

8. Eingaben mit Scanner

Vollständiges Beispiel für eine Zahleneingabe:

import java.util.Scanner;

public class Sandbox {
    public static void main(String[] args) {
        try (Scanner eingabe = new Scanner(System.in)) {
            System.out.print("Wie alt bist du? ");
            int alter = eingabe.nextInt();
            System.out.println("Du bist " + alter + " Jahre alt.");
        }
    }
}

Im Run-Fenster eine ganze Zahl eingeben und Enter drücken.

  • eingabe.nextInt() liest eine ganze Zahl.
  • eingabe.nextLine() liest eine Textzeile.
  • Wenn auf nextInt() eine Texteingabe mit nextLine() folgt, zuerst einmal zusätzlich eingabe.nextLine(); aufrufen. Das verbraucht den übrig gebliebenen Zeilenumbruch.
  • Für den Einstieg setzen wir passende Eingaben voraus.

9. Wiederholen mit while

int versuch = 1;

while (versuch <= 3) {
    System.out.println("Versuch " + versuch);
    versuch++;
}

Der Block wird wiederholt, solange die Bedingung wahr ist. Hier erscheinen die Versuche 1, 2 und 3. Ändert sich die Bedingung nie, kann eine Endlosschleife entstehen.

10. Die wichtigsten Schreibregeln

  • Anweisungen wie Zuweisungen und Methodenaufrufe enden mit ;.
  • Blöcke stehen zwischen { und }. Hinter dem Kopf von if oder while steht kein Semikolon.
  • Groß- und Kleinschreibung zählt: punkte und Punkte sind verschiedene Namen.
  • Variablen klein beginnen und ohne Leerzeichen schreiben: anzahlVersuche.
  • Mit // beginnt ein Kommentar bis zum Zeilenende. Er wird nicht ausgeführt.
  • Beispiele sind einzeln gedacht. Fügt nicht alle Blöcke unverändert zusammen, sonst werden manche Variablen mehrfach angelegt.
